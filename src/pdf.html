Formato

Trascina sulla pagina il riquadro dove deve comparire la firma.
La firma usa SHA-256 ed è compatibile con Adobe Acrobat e con i programmi di verifica italiani. Non contiene una marca temporale (servirebbe una connessione a Internet).

Password per aprire il file

Lascia vuoto se il file deve aprirsi senza password e vuoi solo limitarne l’uso.

Cosa si può fare con il file

Cifratura AES a 256 bit. I limiti sono rispettati da Acrobat e dai lettori più diffusi, ma non da tutti i programmi: la vera protezione è la password per aprire.
